# Fault catalog

| Code | Fault | Safe reaction | Recommended first check |
|---|---|---|---|
| D101 | Door movement blocked | Movement timeout / fault | Mechanical freedom of movement |
| D102 | Open sensor unavailable | Diagnostic event | Sensor and wiring |
| D103 | Closed sensor unavailable | Diagnostic event | Sensor and wiring |
| D104 | Contradictory position sensors | Immediate fault state | Both end-position circuits |
| D105 | Communication loss | Immediate fault state | Controller and bus interface |
| D106 | Supply undervoltage | Immediate fault state | Supply and voltage drop |
| D107 | Motor overcurrent | Immediate fault state | Actuator, mechanics and wiring |
